# 🎨 Interactive Web Projects Collection

A curated collection of premium, single-page web applications showcasing modern web development techniques, advanced animations, and interactive generative art. Each project is built with vanilla HTML, CSS, and JavaScript, focusing on performance and aesthetic excellence.

## 🚀 Key Features

* **✨ Hyper-Realistic UI**: Implementing Glassmorphism, Neumorphism, and deep aesthetic layers using modern CSS.
* **🎥 Smooth Animations**: High-performance, 60FPS physics simulations using HTML5 Canvas and `requestAnimationFrame`.
* **📱 Fully Responsive**: Adaptive layouts that provide a seamless experience across Desktop, Tablet, and Mobile.
* **🎨 Dynamic Icons & Visuals**: Rich use of visual cues, creating an engaging and intuitive user experience.
* **⚡ Zero Dependencies**: Pure, lightweight Vanilla JavaScript for maximum speed and compatibility.

## 🛠️ Technology Stack

* **Structure**: Semantic **HTML5**
* **Styling**: Modern **CSS3** (Variables, Flexbox, Grid, Glassmorphism effects)
* **Logic**: **Vanilla JavaScript** (ES6+, Classes, Canvas API)
* **Performance**: Optimized rendering loops and event handling.

## 📦 How to Run

Since these are standalone web technologies, no installation is required!

1. **Clone or Download** this repository.
2. **Open** the folder.
3. **Double-click `index.html`** to launch the main hub, or open any specific `.html` file directly in your browser.
